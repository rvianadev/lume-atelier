## ✨ Sobre o projeto

A **LUME Atelier** é um projeto acadêmico de desenvolvimento de um site institucional para um estúdio fictício de fotografia profissional, concebido com posicionamento **Premium / Editorial**.

A proposta é apresentar uma experiência digital sofisticada, na qual fotografia, design e tecnologia se encontram para transmitir a essência de uma marca que valoriza a sensibilidade artística, a excelência técnica e a identidade visual.

O site reúne informações institucionais, apresentação dos serviços, uma seleção de trabalhos fotográficos e um canal de contato demonstrativo.

## 🎨 Identidade visual

A identidade visual foi concebida para transmitir sofisticação, elegância e atemporalidade. A linguagem editorial combina tipografia refinada, fotografias e uma paleta inspirada em tons naturais e metálicos.

### Paleta de cores

| Cor | Código | Aplicação |
|---|---|---|
| Preto carvão | `#171717` | Fundos principais e elementos de contraste |
| Off-white | `#F8F6F1` | Fundos claros e áreas de leitura |
| Areia | `#E8E1D6` | Cartões e elementos secundários |
| Bronze | `#A68B6A` | Destaques e elementos de identidade |

### Tipografia

- **Playfair Display:** títulos e elementos de destaque.
- **Montserrat:** textos, menus e elementos de interface.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| HTML5 | Estruturação e semântica do conteúdo |
| CSS3 | Estilização, layouts, identidade visual e responsividade |
| JavaScript | Interatividade, validação e manipulação de elementos |
| Bootstrap 5.3.3 | Grid responsivo e componentes de interface |

O Bootstrap é utilizado por CDN, em conjunto com folhas de estilo próprias. As fontes Playfair Display e Montserrat são carregadas pelo Google Fonts.

## ⚙️ Funcionalidades

- **Navegação responsiva:** menu com acesso às seções da página e comportamento adaptado a dispositivos móveis.
- **Efeito na navbar:** alteração visual durante a rolagem e sublinhado animado nos links ao passar o mouse.
- **Apresentação institucional:** seção sobre o atelier, com missão, visão e valores.
- **Cards de serviços:** apresentação das modalidades de fotografia.
- **Modal dinâmico:** exibição de informações específicas de cada serviço, com conteúdo atualizado por JavaScript.
- **Carrossel de fotografias:** galeria com seis imagens, reprodução automática e controles de navegação.
- **Formulário de contato:** campos para identificação do visitante, seleção do serviço e descrição da solicitação.
- **Validação no navegador:** verificação dos campos obrigatórios e do formato do endereço de e-mail.
- **Feedback de envio:** exibição temporária de mensagem após a validação do formulário.
- **Rolagem suave:** transição entre as seções durante a navegação.

> **Importante:** o formulário tem finalidade demonstrativa. A validação e a mensagem de confirmação são realizadas no navegador; os dados não são enviados nem armazenados em servidor.

## 🚀 Como executar localmente

O projeto é uma página estática e não exige instalação de dependências ou processo de build.

1. Clone o repositório:

   ```bash
   git clone https://github.com/rvianadev/lume-atelier.git
   ```

2. Acesse a pasta:

   ```bash
   cd lume-atelier
   ```

3. Abra o arquivo `index.html` no navegador. Para facilitar o desenvolvimento, também é possível abrir a pasta no Visual Studio Code e utilizar a extensão **Live Server**.

**Conexão com a internet:** necessária para carregar o Bootstrap e as fontes do Google Fonts, utilizados por meio de CDNs.
